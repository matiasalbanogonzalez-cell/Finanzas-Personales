# Finanzas-Personales
# 💰 Control de Gastos Pro - Firebase

Una aplicación web moderna y minimalista para la gestión de finanzas personales, desarrollada con **HTML5**, **CSS3 (Glassmorphism)**, **JavaScript (ES6+)** y **Firebase Firestore**.

## 🚀 Demo
Podés ver la aplicación funcionando en tiempo real aquí:
[https://finanzas-personales-42337.web.app](https://finanzas-personales-42337.web.app)

## ✨ Características
*   **Diseño Moderno:** Interfaz con efecto de vidrio (glassmorphism) y fondo de "blobs" animados.
*   **Persistencia de Datos:** Conexión en tiempo real con Firebase Firestore.
*   **Responsive Design:** Optimizado para usar desde el celular o la computadora.
*   **Gestión de Movimientos:** Registro de ingresos y gastos con cálculo automático de saldo total.
*   **Máscara de Moneda:** Formateo automático de números en pesos argentinos (ARS).

## 🛠️ Tecnologías utilizadas
*   **Frontend:** HTML, CSS, JavaScript.
*   **Backend:** Firebase Firestore (Base de datos NoSQL).
*   **Hosting:** Firebase Hosting.
